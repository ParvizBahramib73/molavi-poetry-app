# راهنمای APK آزمایشی مولوی

## تصمیم فنی

برای نسخه نخست اندروید از **Capacitor 8** استفاده می‌کنیم: رابط Angular و محتوای اپ درون APK بسته‌بندی می‌شود؛ برنامه فقط یک میان‌بر به وب‌سایت نیست. یک پروژه Android/Gradle هنگام ساخت، از روی پیکربندی ثابت تولید می‌شود.

- Android: از نسخه ۷ (API 24) به بعد، در صورت داشتن WebView مناسب
- شناسه آزمایشی پکیج: `com.parvizbahrami.molavi`
- نام برنامه: «مولوی؛ بخوان و بشنو»
- Node: نسخه ۲۲؛ JDK: نسخه ۲۱
- بسته‌های Capacitor: نسخه دقیق 8.0.0
- محل خروجی Angular: `dist/molavi-poetry-app/browser`
- این مرحله حساب کاربری، پرداخت، GPS، دوربین و مجوز دسترسی به فایل‌ها اضافه نمی‌کند.

**دسترسی به اینترنت همچنان برای دریافت اشعار و صوت از گنجور الزامی است.** نمایش آفلاین متن تمام کتابخانه یا پخش در پس‌زمینه تضمین نشده است. فایل‌های Angular در خود APK قرار می‌گیرند و برای اجرای رابط اولیه نیازی به باز کردن GitHub Pages نیست.

## دریافت APK تست

۱. در GitHub به بخش Actions > Android Debug APK برو.
۲. اجرای موفق مربوط به آخرین Pull Request یا شاخه main را باز کن.
۳. زیر بخش Artifacts، فایل `Molavi-Android-Debug-APK` را دانلود کن.
۴. فایل ZIP را استخراج کن؛ فایل `Molavi-Debug.apk` و `SHA256SUMS.txt` داخل آن است.
۵. در اندروید، پس از اطمینان از منبع، به مرورگر یا فایل‌منیجر اجازه نصب از این منبع را بده و APK را نصب کن. مجوز را بعد از نصب می‌توانی خاموش کنی.

APK **debug-signed** فقط برای آزمون است و نباید مستقیماً در بازار یا Google Play منتشر شود. خروجی تست از GitHub Actions تا ۱۴ روز نگه داشته می‌شود؛ برای نسخه جدید دوباره build بگیر.

## ساخت روی کامپیوتر توسعه‌دهنده

نیازمندی‌ها: Node 22، Android SDK، Java 21 و Git. به‌عنوان نخستین اقدام:

```bash
npm ci
npm install --no-save --no-package-lock \
  @capacitor/core@8.0.0 @capacitor/android@8.0.0 @capacitor/cli@8.0.0
npm run build -- --configuration=production --base-href=/
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

فایل خروجی: `android/app/build/outputs/apk/debug/app-debug.apk`. اگر پوشه `android` وجود دارد، `npx cap add android` را نزن؛ فقط `npx cap sync android` را اجرا کن.

**تصمیم آگاهانه مرحله آزمایشی:** بسته‌های Capacitor در CI با شماره نسخه دقیق نصب می‌شوند، بدون تغییر دادن lockfile اپ وب. قبل از انتشار فروشگاهی، پروژه Android باید در مخزن ثبت، وابستگی‌ها با lockfile قفل و Build تکرارپذیر تأیید شود.

## ماتریس تست واقعی

| شناسه | سناریو | معیار قبولی |
|---|---|---|
| A01 | نصب فایل APK از GitHub | بدون خطای «App not installed» نصب شود |
| A02 | باز شدن برنامه در حالت آفلاین | پوسته برنامه باز شود و متن مناسب برای قطع اینترنت نمایش داده شود |
| A03 | دریافت شعر پیش‌فرض با اینترنت | متن مثنوی بدون صفحه سفید و با حروف فارسی صحیح دیده شود |
| A04 | جست‌وجو با «بشنو از نی» | نتیجه و پیش‌نمایش متن از API دریافت شود |
| A05 | پخش صوت و توقف/ادامه | صدا شروع، متوقف و ادامه پیدا کند |
| A06 | کلید/ژست Back در Android | بدون گیر کردن یا خروج ناخواسته بتوان در صفحه‌ها حرکت کرد |
| A07 | بازگشت به برنامه از Recent Apps | برنامه بی‌دلیل دوباره از صفحه اول شروع نشود |
| A08 | ذخیره شعر و خروج و ورود مجدد | علاقه‌مندی‌ها و آخرین موقعیت پخش حفظ شوند |
| A09 | تغییر اندازه فونت سیستم و حالت راست‌به‌چپ | نوشته‌ها خوانا باشند و دکمه‌ها بریده نشوند |
| A10 | اندروید ۸ و اندروید ۱۴/۱۵/۱۶ | بارگذاری شبکه، پخش و دسترسی به کنترل‌های پایین صفحه بررسی شود |
| A11 | قطع اینترنت هنگام شنیدن | خطای واضح نمایش داده شود؛ برنامه کرش نکند |
| A12 | دانلود تصویر اشتراک شعر | در سیستم Share یا گالری به‌صورت قابل فهم عمل کند |

**وضعیت تست‌های دستی:** هنوز انجام نشده‌اند. CI فقط موفقیت ساخت فایل APK را بررسی می‌کند. نصب روی سخت‌افزار واقعی، عملکرد WebView/CORS، دکمه بازگشت، صدای پس‌زمینه و منوی Share نیازمند آزمون گوشی هستند.

## مرحله انتشار عمومی

۱. بررسی دقیق حق استفاده/انتشار خوانش‌های صوتی و داده‌ها از گنجور.
۲. طراحی آیکون و Splash نهایی و ثبت پروژه Android برای نسخه‌های آینده.
۳. برطرف کردن ایرادهای ماتریس بالا و افزودن نسخه‌گذاری (`versionCode` افزایشی).
۴. ایجاد کلید امضای **release** اختصاصی و نگهداری امن خارج از مخزن؛ ساخت APK امضاشده برای بازار و AAB برای Google Play.
۵. آماده‌سازی سیاست حریم خصوصی، تصاویر فروشگاهی، اطلاعات تماس و توضیحات فارسی برنامه.
۶. دریافت تأیید نهایی مالک برنامه پیش از انتشار عمومی.

این سند گزارش تست دستگاه واقعی نیست؛ معیار و برنامه آزمایش است.
