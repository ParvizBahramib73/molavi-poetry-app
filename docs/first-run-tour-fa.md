# تور آموزشی استفاده اول مولوی

هدف: در اولین بار استفاده، حتی فردی که تجربه کمی با گوشی دارد در پنج مرحله کوتاه با برنامه آشنا شود. هیچ آزمون، ثبت‌نام یا دسترسی اینترنتی برای خود تور لازم نیست.

## پنج مرحله

| گام | پیام اصلی | کار واقعی در برنامه |
| --- | --- | --- |
| ۱ | خوش آمدی | معرفی شعر و صدای مولانا، بدون حساب |
| ۲ | گوش بده | بخش «شنیدن» و دکمه «پخش» |
| ۳ | شعر را پیدا کن | بخش «جست‌وجو»، حتی با چند واژه |
| ۴ | راحت بخوان | «خواندن متن» و درشت کردن نوشته |
| ۵ | ذخیره کن | «علاقه‌مندی» و «کتابخانه من» |

## رفتار محصول

- تور به‌صورت خودکار فقط در اولین اجرا، بر اساس حافظه محلی دستگاه، نمایش داده می‌شود.
- «رد کردن آموزش»، ضربدر و کلید Escape آن را می‌بندند.
- دکمه‌های «بعدی»، «قبلی»، «شروع استفاده» و نشانگر مراحل دیده می‌شوند.
- رد کردن و تکمیل کردن به یک اندازه به انتخاب کاربر احترام می‌گذارند و در بازدید بعدی تور خودکار ظاهر نمی‌شود.
- راهنما در «کتابخانه من» با دکمه «راهنمای استفاده» همیشه قابل تکرار است.
- تنظیم به حساب کاربری متکی نیست. با پاک شدن داده‌های مرورگر یا نصب مجدد برنامه ممکن است تور دوباره نمایش داده شود.
- برنامه و داده‌های علاقه‌مندی هیچ تغییری با اجرای تور نمی‌کنند.
- تور برای وب، PWA و نسخه بعدی اندروید از یک کامپوننت Angular استفاده می‌کند.

## پذیرش و بررسی کاربردپذیری

| آزمون | معیار |
| --- | --- |
| نصب یا باز کردن روی دستگاه جدید | تور نمایش داده شود |
| باز کردن مجدد پس از رد کردن | تور خودکار نمایش داده نشود |
| رفتن جلو/عقب | ترتیب و شمارنده مراحل صحیح باشد |
| پایان آخرین مرحله | تور بسته و برنامه قابل استفاده باشد |
| باز کردن دوباره از کتابخانه | تور از گام اول شروع شود |
| حرکت با Tab و Shift+Tab | تمرکز در دیالوگ بماند |
| Escape | تور بدون از دست دادن داده‌ها بسته شود |
| صفحه کوچک با فونت بزرگ | متن و دکمه‌ها کاملاً قابل خواندن باشند |
| قطع اینترنت | خود راهنما به اینترنت نیاز نداشته باشد |
| گوشی اندروید | باز کردن تور، بستن و لمس دکمه‌ها با WebView واقعی تست شود |

**تست انسانی هنوز انجام نشده است**. آزمون با داوطلبانی از گروه‌های سنی و سواد دیجیتال مختلف، با رضایت آنان، قبل از انتشار فروشگاهی لازم است.

## حریم خصوصی

تنها کلید `molavi:onboarding:v1:seen` در `localStorage` ذخیره می‌شود تا وضعیت مشاهده/رد تور مشخص باشد. نه نام، نه زمان تعامل و نه اطلاعات شخصی جمع‌آوری نمی‌شود.

## محدودیت

این نسخه یک تور تصویری-متنی مرحله‌ای است، نه تور پیچیده با کلیک واقعی روی کنترل‌های زیرین. به همین دلیل هیچ‌کدام از عملیات پخش، جست‌وجو یا ذخیره شعر، خودکار یا بدون رضایت کاربر اجرا نمی‌شوند.
